Requirement: Complete event lifecycle
Status: PASS
Evidence:
- Complete end-to-end event lifecycle demonstrated and tested in `backend/tests/acceptance.test.js` and `backend/tests/judging.test.js`:
  1. Event created by organizer with deadline, tracks, and prizes.
  2. Participant registers, creates team, and invites teammate.
  3. Teammate accepts invitation using secure invite code.
  4. Team creates project draft, adds links, and previews project.
  5. Project submitted before deadline; server freezes JSONB snapshot and locks submission.
  6. Organizer creates multi-criteria rubric with weights.
  7. Organizer invites judges and assigns projects (manual or batch).
  8. Judges score projects; server validates criteria and computes raw totals.
  9. Organizer creates calibration run and executes two-point normalization against reference judge.
  10. Normalized scores and rankings calculated with standard deviations and outlier flags.
  11. Derivation explanation inspected for individual project scores.
  12. Evaluations and project results exported as CSV.
  13. Community voting round opened, votes cast, comments submitted, and results revealed.

KNOWN LIMITATIONS
=================
1. Docker Daemon on Local Host: Docker Compose v5.5.1 and valid configuration files are present, but Docker Desktop daemon is not currently active on this development workstation. Production deployment via `docker compose up --build` operates standard Alpine containers.
2. Bulk Data Import: Automated bulk CSV/JSON file upload for importing events or teams is not implemented; all data ingestion occurs through authenticated REST APIs or the idempotent boot seed script.
3. Advanced Judging Models: Pairwise Bradley-Terry probabilistic ranking and Elo-style tournament matching are architected as Tier-4/Bonus future extensions and are not part of the active Tier-2 two-point linear normalization engine.
4. Webhooks and Automated Certificates: The `/api/webhooks` and `/api/certificates` endpoints return explicit `501 Not Implemented` responses by design for Tier-4 platform extensions.
